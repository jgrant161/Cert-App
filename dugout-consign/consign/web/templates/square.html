Connect Square

  1. Sign in at developer.squareup.com with the shop's Square login and create an application (name it “Dug Out Consignment”).
  2. Open it, choose Production, and copy the Access token.
  3. Under Locations, copy the location id for the store.
  4. Set SQUARE_ACCESS_TOKEN and SQUARE_LOCATION_ID where the portal runs and restart it. (Try SQUARE_ENVIRONMENT=sandbox with sandbox credentials first if you like.)

Until then you can still use Square: download an import file for Square's Items page (Items → Import), and the printed labels scan the same way.
